# 骨兄弟的马里奥 · 设计架构

一句话：双人同屏、蓝天空地、旗杆终点的像素闯关。外壳是 UT，骨架是马里奥。

## 一、屏幕与画风

- 逻辑分辨率 416×224（26×14 格，格子 16px），canvas 等比放大，最近邻缩放，不糊。
- 天空 #5c94fc，云是白的，地面砖棕黄，砖墙带缝。
- 地下关（下水道）背景纯黑，砖墙灰蓝，只靠管道口的光。
- 字体 Zpix，12px 对齐的像素字，带中文，OFL 授权，随便用。

## 二、两个角色

| | 碰撞盒 | 速度 | 跳跃 | 贴图 |
|---|---|---|---|---|
| sans | 10×24 | 2.0 | -7.2 | 17×30 |
| papyrus | 12×34 | 1.6 | -8.4 | 15×42 |

- 同屏双人。sans 用 A/D/W，papyrus 用 方向键。
- 手机：左半屏一套圆钮给 sans，右半屏一套给 papyrus，两拇指各管一个。
- 互补设计：矮通道只有 sans 钻得进，重压力板只有 papyrus 站得动。谁也别想一个人通关。

## 三、关卡

- 每关 400 格（6400px），正常走两分钟量级，全关三关。
- 1-1 蓝天白云地面关；1-2 下水道（踩管道进去，黑底砖墙）；1-3 骨兄弟城堡，假砖和机关都在这。
- 数据不硬写整关，用分段拼：每段一个多行字符串，`buildLevel()` 按顺序接起来。
- 校验脚本开工前跑一遍：段宽对齐、断崖跳得到、起点终点都在。

字符表：

| 字符 | 意思 |
|---|---|
| `#` | 地面 |
| `=` | 平台 |
| `B` | 普通砖，顶一下出金币 |
| `?` | 问号砖，顶出道具 |
| `x` | 碎砖，顶或踩就碎 |
| `P` | 管道，按下钻 |
| `f` | 旗杆底座 |
| `|` | 旗杆 |
| `^` | 尖刺 |
| `.` | 空 |

## 四、砖与机关

- 问号砖顶出道具会弹一下再落回砖面，砖变成空砖，不能顶第二次。
- 碎砖贴图必须一眼认出：砖面一道斜裂缝，颜色比普通砖浅一档。宁可丑，不能像。
- 假砖只留 1-3，外观和普通砖一模一样，踩上去半秒后塌。

## 五、怪物与道具（参考 UT 原作）

怪物四条，够摆满一关：

- Froggit：地上小跳，踩一脚就没了
- Whimsun：空中飘，踩不到，只能躲
- Moldsmal：原地不动，踩上去弹一下
- Napstablook：飘着哭，被碰一下溅墨汁，减速两秒

道具四样：

- 番茄酱瓶：跑速加成十秒
- 雪镇汤：无敌三秒，碰到怪物不掉
- 怪物糖：加一条命
- Annoying Dog：彩蛋，拿到后它会一直跟着叫

## 六、贴图

- 现在这套够先跑：sans 左右各 17×30，papyrus 左右各 15×42，都在视频素材库里。
- 走路动画先按两帧一循环。你从 UT 那边拿的话放 `mario/assets/`，命名 `sans_walk_1.png`、`papyrus_walk_1.png`，左右分开我自动镜像。
- 你没给之前我拿站立图占位，不耽误跑。
- 所有图内联成 dataURI，单文件也能双击打开。

## 七、文件结构

```
mario/
  index.html     画布、加载、开始画面
  game.js        主循环、物理、碰撞、相机、角色
  levels.js      关卡分段数据 + buildLevel
  assets.js      贴图 dataURI 表
  assets/        原始 png（线上用）
  font/zpix.woff2
```
